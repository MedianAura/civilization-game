| Boundary | Description |

| npm registry -> node_modules | Untrusted third-party package code enters the project via `npm install`; supply-chain risk |
| Vite dev server -> browser/LAN | Local dev server serves source over HTTP; if bound beyond localhost, exposes source and enables LAN-local access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering / Elevation of Privilege | node_modules (npm supply chain) | mitigate | All dependency versions in package.json are exact/narrow-pinned per RESEARCH.md (e.g. `typescript: "~5.9.3"`, `phaser: "4.1.0"`) rather than `latest` or bare ranges, preventing silent major-version drift (the exact TypeScript 7.x incompatibility RESEARCH.md flags) |
| T-01-02 | Information Disclosure | Vite dev server (vite.config.ts) | accept | `server.port: 8080` with no `server.host` override means Vite binds to localhost only by default; no secrets or user data exist in Phase 1 source to disclose |
| T-01-03 | Tampering | Pre-commit hook (.husky/pre-commit) | mitigate | lint-staged only runs `eslint --fix`/`prettier --write` on staged files — no arbitrary shell execution beyond the pinned toolchain, limiting hook-injection blast radius |
</threat_model>
